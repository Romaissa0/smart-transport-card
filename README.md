
# Smart Transport Card System

## Overview

A smart transport ticketing system designed to support a reusable transport card, a digital wallet, and time-limited tickets.

The project will use a Java backend and explore Java Card technology through a simulator.

## Main Objectives

- Manage transport card identities.
- Maintain a wallet balance and record transactions.
- Purchase transport tickets.
- Activate a ticket on its first successful validation.
- Allow eligible transport journeys during a 120-minute validity period.
- Validate tickets and reject expired or invalid tickets.

## Planned Components

- **Backend:** Java application for business rules and ticket management.
- **Web dashboard:** Interface for viewing and managing the system.
- **Java Card:** Simulated card-side functionality.
- **Validator:** Component that checks a passenger's ticket.

## Development Approach

The project will be developed incrementally, starting with requirements and system design before implementation.

## Status

Requirements and architecture are being defined.
